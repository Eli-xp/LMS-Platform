# LMS-Platform

A scalable course management platform featuring authentication, payments, course publishing, and student enrollment, built with Next.js &amp; Nest.js.

## Features

- Authentication with BetterAuth
- Course management
- Student enrollment
- zarinPal payments
- Admin dashboard
- Responsive UI
- TypeScript
- App Router

## Tech Stack

### Frontend

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS

### Backend

- Next.js Route Handlers
- Server Actions
- Better Auth

## Getting Started

```bash
pnpm install
pnpm dev
```
